# Catalog of the Van Gestel video rides

Generated by `pnpm fetch:video-catalog` (`scripts/fetch-video-catalog.ts`); ridrs Scenic (`web/scenic`) imports it and serves its routes, and the app reads them from Scenic (`plugins/video-source-scenic`, ADR 0103): the app does not bundle this folder. Do not edit by hand, except the peak lists, the image prompts and the thumbnails made from them. `index.json` lists every route with its categorised climbs, `<id>/package/` holds the route's package without its video, every other file of it byte for byte (ADR 0095), `<id>/peaks.txt` lists the names of the route's categorised summits in order (kept when the tool runs again), `<id>/thumbnail.jpg` the route's small picture for its card, 800 px wide (fetched from the site only where none is there yet; the tool never replaces one), `<id>/overlay/` the files that improve the route's package (ADR 0094), named as its entries: today its picture in full size, `preview.jpg` or the PNG its control file names; the tool lists them with their hashes in `index.json` and never writes them, `<id>/profile.svg` a picture of the elevation profile with the climbs' categories, which the app does not use (ADR 0070). `<id>/image-prompt.txt` is written by hand, not by the tool: a prompt for an image generator to make the route's own thumbnail, each built around something only that ride has.
