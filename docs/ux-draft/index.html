ridrs UX draft

Clickable prototype, static HTML, no build. Every page has a state switcher (top) and a note explaining the state. Not app code. Concepts, rules and roadmap: README.md.

Flow

 first start:  Welcome ─► Bluetooth ─► Rider ─► Setup (first) ─► Main
 later starts: Setup (reconnect) ─ all settled, 3 s ─► Main        Setup collapses into the device indicator
 Setup:        connects every kind with one candidate; a conflict is picked inline, no popup
 Main:         [● Trainer ● Power ● HR ● Pixel 8 ▾]   [Start ride] ─► Activity ─► Ride saved ─► Main
               tap indicator ─► rows ─► Device page (choose device, "connect via")
               new device later ─► amber badge only ─► Device page (review)
 Companion:    Connection ─► Add companion ─► paired ─► its devices are merged with this Mac's
               duplicates shown once · this Mac first · per-device "Pixel 8 first" · automatic failover
