Each decision has the reason behind it, and the source where it is recorded in more detail. "User" means decided by the project owner; "dev" means decided during development on measured evidence. Dates are 2026-11.

Elsewhere, Copernicus with its FLM-filled pixels replaced by NASADEM goes through the P13 filter unchanged. With no extra data cached, the output is exactly P13. ## Algorithm (pipeline)

| # | Decision | Why | Source |
|---|---|---|---|
| A1 | **Dense HMM map matching** over (directed OSM edge, cell of 30·κ m), with Student-t heading-increment emissions, exact Viterbi and forward–backward. It replaced quanta (curve–straight–curve) voting. | Quanta matching failed (negative PoC, weak votes). The dense HMM found Grimone at 99.8 % (fed with GPS) and works on vms. (Dev) | FINDINGS "Fable step 3" |
| A2 | **A 2-D calibration scan** over focal scale f_eff × distance scale κ, with ln κ per transition. The **grid extends itself adaptively** when the peak sits on its edge: up to 3 rounds, f_eff 150–900, κ 0.5–7. | Camera and scale are unknown per video; Madone's peak was at the edge. (Dev, User) | PIPELINE_CLI |
| A3 | **Heading from far features** (a rotation-only fit with an x²/f term), with vms as fallback. | Near-road flow mixes translation and rotation. Far yaw brought Amalfi to decoy rank 1. (Dev) | FINDINGS |
| A4 | **Local pass**: decode again in a 300 m corridor with all road classes (incl. residential) and **15 m** nominal steps. | The search map has no residential streets: the Rond-Point Saint-Roch was a dead end. 10 m steps fail on a synthetic town, because a video turn spreads over 20–30 m while a map junction is a kink. (Dev) | FINDINGS |
| A5 | **A road-class prior in the local pass**: 15 nats/km on classes outside the vehicle's search classes. | Avenue Cernuschi (residential) beat the Cours René Coty by 7.5 nats over 1 km. | A6 | **Measured standstills**: a gap between tracks whose pairs are at least 70 % well fitted gets its measured vms distance, not the mean speed. | A stop at a light was filled with up to 130 m never driven. (Dev / Fable) | FINDINGS |
| A7 | **Dense heading alignment** (a monotone 1-D Viterbi on a 2 m grid, with the path heading smoothed across nodes). Used everywhere, it made Roanne worse (7 m), because straights carry no heading. (Dev / Fable) | FINDINGS |

## App engineering

| # | Decision | Why |
|---|---|---|
| E1 | **Video served by a local HTTP media server** (127.0.0.1, random token, Range support), not the `asset://` protocol. | WebKit copied asset responses on the main thread, causing the beachball every few seconds. |
| E2 | **Title → place candidates**: emojis, tags and IDs are stripped, and name runs containing place keywords (col, passo, lago …) are tried first. A hit with local map data is preferred. | "Route du Col de la Madone 4K HDR 🇫🇷 …" found nothing before. |
| E3 | **Square map** (max 80 vh); the bbox follows a resized view; the running job's area is shown dashed. | User requests. |
| E4 | **The dark-mode map filter is applied per tile**, not on the tile pane. | WebKit painted a filtered, translated pane only in part (a 512 px square). It is to be verified in the real app. |
| E5 | **Everything is in one folder** (`video2gpx/` with `research/`). Large data stays outside the repository. | User request, 12 Nov. The research code is now under git; data is not. |
| E6 | **Release profile `opt-level = "z"`, LTO, strip, but no `panic = "abort"`.** | Abort would save a few hundred kB, but a panic in one worker thread (media server, child-process readers) would then end the app while a pipeline job runs. No `catch_unwind` exists that would need unwinding; the choice is about staying alive. |
| E7 | **Tools are looked up, not bundled**: setting, PATH, Homebrew, `/usr/local`, `/usr/bin`, MacPorts, `~/.local/bin`, then the login shell (`command -v`, name passed as an argument; a miss is remembered for 30 s). ffmpeg and ffprobe are required, yt-dlp (`ytdlp` setting or `RSM_YTDLP`) is optional. A wrong path in the settings is an error and is never replaced by a search. Versions and the sidecar check are cached per file and modification time, because the environment check runs on every window focus. | A GUI app has a minimal PATH. |
| E8 | **`follow_import` queues the run**: a start during an import is accepted, reports `{type: "input"}` events and begins with the complete file. Reading a growing file (plan-speed 5.4 C) is not built; `processable` is always false. | The horizon calibration needs the whole video, so a head start would not give identical results. |
| E9 | **The DMG is an overlay config** (`src-tauri/tauri.dmg.conf.json`, used as a second `--config`), so the plain and the sidecar builds stay as they are. | |
| E10 | **The UI is a workflow of stages** (Start → Einrichten · Berechnung · Ergebnis · Höhe · Export, plus Werkzeuge, Kartendaten, Einstellungen) on hash routes. Map and `<video>` are created once and only re-laid out per stage; views build their DOM once and patch it. | One screen held everything and put the result below the fold; re-rendering on every event lost the focus. (User goal 3, RC session; FEATURE_ui_redesign.md) |
| E11 | **Vanilla TypeScript stays** (no framework, no CSS framework); Leaflet is the only runtime library. | About eight views and one store; a framework would add 40–130 kB and a rewrite of working map and player code. (RC plan U-principles) |
| E12 | **Tints are explicit tokens, the build target stays Safari 15**; `color-mix` only as a progressive border with an `@supports` fallback. | The system WKWebView of older macOS lacks `color-mix` (Safari 16.2). (Plan U8) |
| E13 | **Werkzeuge never runs `brew` or installs anything**: it shows the `brew install …` line for what is missing, the Homebrew address as text, own paths. yt-dlp is shown as optional, only for own templates that call it. | P2/P7: the user installs and is responsible; a GUI install would need a login shell and a password prompt. (Plan U5; no yt-dlp preset, maintainer) |
| E14 | **A project can be left or closed while its run goes on**; only a second run is refused. An activity chip in the bar leads back. | The run belongs to the app, not to the open screen. (Plan U4) |
| E15 | **UI verification by script**: `pnpm ui-shots` drives the installed Chrome with `playwright-core` and checks every mock scenario in light and dark with `axe-core` (WCAG 2.1 A/AA), console errors, overflow and focus. Both are devDependencies only. | Repeatable screenshots and accessibility checks without a browser download or a bundle cost. (Plan U7, maintainer) |
