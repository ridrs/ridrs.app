# Catalog of the Van Gestel video rides

Generated by `pnpm fetch:video-catalog`; do not edit by hand, except the peak lists, the image prompts and the thumbnails made from them. `index.json` lists every route, `<id>/route.json` holds its profile, path, notes, segments and categorised climbs, `<id>/peaks.txt` lists the names of the route's categorised summits in order (kept when the tool runs again), `<id>/thumbnail.jpg` a picture of the route (fetched from the site only where none is there yet; the tool never replaces one), `<id>/profile.svg` a picture of the elevation profile with the climbs' categories, which the app does not use (ADR 0070). `<id>/image-prompt.txt` is written by hand, not by the tool: a prompt for an image generator to make the route's own thumbnail, each built around something only that ride has.

The routes, their tracks, notes and pictures are by Fred Van Gestel, [cycling.vangestel.online](https://cycling.vangestel.online/indoor/videos/), licensed under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).
