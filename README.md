# ridrs

Open-source, modular, and extensible indoor cycling platform.

## Repository Structure

- `web/`: Cloudflare Worker application serving the project web page ([ridrs.app](https://ridrs.app)).
- Other directories will contain the source code for native applications, modules, and tools.
