# Test Vectors

Workout files for the importers' round trips and cross checks (ADR 0081, 0084), one folder per format: `zwo/`, `fit/`, `erg/`, `mrc/`, `tcx/`, `intervals/`. Real files from the formats' documentation or exported by the services, where their licence allows them here; else hand-written ones from the public specification. Never a file made by ridrs' own encoder alone. Broken and unusual files are included. Each folder's README names the source and licence of every file.
